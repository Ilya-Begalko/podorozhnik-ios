# 🚌 Подорожник — баланс транспортной карты

Простое iOS-приложение для учета баланса транспортной карты «Подорожник» (Санкт-Петербург).

Приложение не взаимодействует с официальными сервисами и не считывает данные с карты. Баланс ведется вручную и помогает быстро контролировать остаток средств и историю поездок.

## Возможности

### 💰 Текущий баланс
- Отображение текущего остатка на карте.
- Крупный и удобный интерфейс для быстрого просмотра.

### ➕ Пополнение баланса
- Ввод любой суммы пополнения.
- Автоматическое сохранение операции в истории.

### 🚃 Оплата поездки
- Одно нажатие списывает стоимость поездки.
- Текущая стоимость поездки — 65 ₽.
- Кнопка автоматически блокируется при недостаточном балансе.

### ✏️ Ручное изменение баланса
- Возможность установить любое значение баланса вручную.
- Удобно после проверки остатка через валидатор или официальные сервисы.

### 📜 История операций
Сохраняется история всех действий:
- Пополнения
- Поездки
- Ручные изменения баланса

Для каждой операции отображаются:
- Тип операции
- Дата и время
- Сумма изменения

### 🗑 Сброс данных
- Очистка баланса и истории операций одной кнопкой.

### 💾 Автоматическое сохранение
Все данные сохраняются локально на устройстве и восстанавливаются после перезапуска приложения.

## Хранение данных

Приложение хранит данные только локально:

- Баланс
- Историю операций

Используются:
- JSON-файл в Documents Directory
- UserDefaults (через App Group для поддержки виджетов)

Никакие данные не отправляются на внешние серверы.

## Технологии

## Установка

### Через Xcode

1. Откройте проект в Xcode.
2. Выберите свой Apple ID в разделе Signing & Capabilities.
3. Подключите iPhone.
4. Нажмите Run.

Для личного использования достаточно бесплатного Apple ID.

## Ограничения

- Приложение не умеет считывать реальный баланс карты.
- Все изменения баланса выполняются вручную пользователем.
- Стоимость поездки захардкожена как 65 ₽ и может отличаться от актуального тарифа.

## Конфиденциальность

Приложение не собирает аналитику, не отслеживает действия пользователя и не передает данные третьим лицам.

## Статус проекта

Проект создан для личного использования и изучения SwiftUI.
