# 🚌 Подорожник — баланс транспортной карты

Простое iOS-приложение для отслеживания остатка на транспортной карте «Подорожник» (Санкт-Петербург).

## Зачем

Официальное приложение громоздкое, а иногда нужно просто быстро глянуть баланс
и отметить списание после поездки — без лишних шагов.

## Функционал

- 💰 Отображение текущего остатка на карте
- 🚃 Кнопка списания за поездку (−65 ₽ за одно нажатие)
- ✏️ Ручное редактирование баланса (например, после пополнения)
- 📲 Виджет для рабочего стола — баланс всегда на экране
- 💾 Баланс сохраняется между запусками

## Стек

- Swift + SwiftUI
- WidgetKit
- UserDefaults / App Groups

## Установка

Проект предназначен для личного использования.
Открой в Xcode, подключи iPhone, нажми Run.
Платный Developer Account не требуется.

## Заметки

Стоимость поездки захардкожена как 65 ₽ — актуально для Санкт-Петербурга на момент разработки.
